# VirtCruise v0.7.0 Frontend

Released: 2026-08-03

The v0.7.0 frontend is the exact immutable RC4 archive accepted in Production Beta. It provides the
customer Booking and Financial portals, Bank Transfer and replacement journeys, Receipt/payment
history, and the responsive Finance Operations and Financial portals.

Production launches in Manual Finance mode. Customers see approved Finance contact information,
their authoritative Booking or invoice reference and currency, plus explicit unpaid/unconfirmed
wording. Bank details, review creation and proof upload are unavailable. The accepted multi-bank
SELF_SERVICE presentation remains ready for a separately approved operational activation.

The browser uses application-specific readiness and local/system fonts, has no public runtime
dependency, performs no client-side accounting, and passed desktop, tablet, mobile, keyboard,
storage, console, network and exact-origin CORS acceptance.

Known limitations: the release provides no bank API, gateway, OCR or automatic reconciliation;
SELF_SERVICE requires the approved production bank workbook and a controlled mode switch.
